# Projetos Padrões de Sítios II

[Github Pages](https://jguilherrme.github.io/cardapio)

## Atividade: Cardápio

Projeto desenvolvido para a disciplina **Projetos Padrões de Sítios II**, com o objetivo de criar um cardápio digital para a empresa **Tokio**, localizada em **Santa Fé do Sul - SP**.

O site foi desenvolvido pensando na organização das informações e na identidade visual da empresa. As cores utilizadas foram escolhidas com base na logo da Tokio, principalmente **preto, vermelho e branco**.

O cardápio foi dividido em categorias para facilitar a navegação e a visualização dos produtos, como sushi, entradas, combos, cervejas e bebidas.
